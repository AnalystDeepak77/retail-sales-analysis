## Retail Sales Analysis Dashboard

End-to-end data analytics project covering the full workflow: data cleaning, database management, and dashboard design.

## Project Overview

This project analyzes retail sales data (3,998 records) to uncover business insights around regional performance, product categories, sales trends, customer segments, and discount impact.

## Tools Used

** Microsoft Excel => Data cleaning and preprocessing
** MySQL           => Database management and SQL querying
** Power BI        => Interactive dashboard design and data visualization

## Project Workflow

1. **Data Cleaning (Excel):** Cleaned a raw retail sales dataset — handled duplicates, missing values, inconsistent date formats, and standardized text fields (Region, Segment, Ship Mode).

2. **Database & Analysis (SQL):** Built a MySQL database and wrote SQL queries to generate 5 key business reports:
   - Region-wise Sales & Profit
   - Category-wise Performance
   - Monthly Sales Trend
   - Segment-wise Performance
   - Discount Impact on Profit Margin
   
    [View SQL queries](sql_queries.sql)

3. **Dashboard (Power BI):** Designed an interactive dashboard featuring KPI cards, bar/line/donut charts, and slicers (Region, Category, Year) for dynamic filtering.

## Key Insights

  - West region generates the highest sales and profit among all regions
  - Electronics is the top-performing category by revenue
  - Company maintains a discipline of never exceeding 20% discount on any order
  - Consumer segment contributes the largest share of total sales (~43%)
